================================================================================
                        BOT WRESTLING - MINDSPARK COEP
                           COMPLETE CONNECTIONS LIST
================================================================================

--------------------------------------------------------------------------------
1. BATTERY → BUCK CONVERTER
--------------------------------------------------------------------------------

   Battery (+) → Buck IN+
   Battery (−) → Buck IN−

--------------------------------------------------------------------------------
2. BATTERY → MDD20A
--------------------------------------------------------------------------------

   Battery (+) → MDD20A B+
   Battery (−) → MDD20A B−

--------------------------------------------------------------------------------
3. BUCK CONVERTER → ESP32
--------------------------------------------------------------------------------

   Buck OUT+ (5V) → ESP32 VIN
   Buck OUT−      → ESP32 GND

--------------------------------------------------------------------------------
4. BUCK CONVERTER → RECEIVER
--------------------------------------------------------------------------------

   Buck OUT+ (5V) → Receiver VCC
   Buck OUT−      → Receiver GND

--------------------------------------------------------------------------------
5. RECEIVER → ESP32
--------------------------------------------------------------------------------

   CH1 Signal → ESP32 GPIO 18  (Steering)
   CH3 Signal → ESP32 GPIO 19  (Throttle)
   CH5 Signal → ESP32 GPIO 23  (Emergency Stop)

--------------------------------------------------------------------------------
6. ESP32 → MDD20A
--------------------------------------------------------------------------------

   ESP32 GPIO 25 → MDD20A PWM1  (Right side speed)
   ESP32 GPIO 27 → MDD20A DIR1  (Right side direction)
   ESP32 GPIO 14 → MDD20A PWM2  (Left side speed)
   ESP32 GPIO 12 → MDD20A DIR2  (Left side direction)
   ESP32 GND     → MDD20A GND

--------------------------------------------------------------------------------
7. MDD20A → MOTORS
--------------------------------------------------------------------------------

   MDD20A M1A → Front-right motor (+)  ─┐
   MDD20A M1A → Rear-right  motor (+)  ─┘ (parallel)

   MDD20A M1B → Front-right motor (−)  ─┐
   MDD20A M1B → Rear-right  motor (−)  ─┘ (parallel)

   MDD20A M2A → Front-left  motor (+)  ─┐
   MDD20A M2A → Rear-left   motor (+)  ─┘ (parallel)

   MDD20A M2B → Front-left  motor (−)  ─┐
   MDD20A M2B → Rear-left   motor (−)  ─┘ (parallel)

================================================================================
                           END OF CONNECTIONS LIST
================================================================================
